
## Assignment Title :  Basic Problems Solving Using Java



## Description :

Different problems are implemented to develop fundamental programming skills. The problems include character counting, swapping numbers, and checking substrings. It also covers finding the sum of prime numbers and checking whether a number is a palindrome. A basic calculator is implemented using Java programming concepts such as operators and control statements. The assignment also includes reversing a string to practice string manipulation techniques. Overall, these problems help to improve logical thinking, problem-solving ability, and Java programming skills.


## 💡Key Concepts Used :

(i) Variables and Data Types – Different types of data such as characters, strings, integers, and floating-point numbers are stored and processed.
(ii) Operators and Expressions – Arithmetic, relational, logical, and assignment operators are used to perform calculations and comparisons.
(iiii) Conditional Statements – if-else and switch-case are used for decision-making and implementing a basic calculator.
(iv) Loops and Iteration – for, while, and do-while loops are used for repeated tasks such as counting, prime numbers, and palindrome checking.
(v) String and Character Manipulation – Strings and characters are processed for character counting, substring checking, and reversing strings.
(vi) Methods and Problem-Solving Techniques – Functions/methods are used to organize code and solve problems such as swapping numbers, calculating sums, and other basic tasks.


## ✨Features :
